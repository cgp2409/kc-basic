# Marca KC Digital Magic

Logo: sobre rosado pastel con "KC" en ciruela (Cormorant Garamond 700 cursiva, convertido a curvas), sello de cera ciruela y destellos dorados. Usa la paleta de la web: rosa #F2C4DE / #E7A9CD, crema #F7EFE5, ciruela #8E2A7E, oro #B8955A.

| Archivo | Uso |
|---|---|
| `kc-perfil-1080.png` / `kc-perfil.svg` | Foto de perfil de Instagram y Facebook (fondo crema) |
| `kc-logo.svg` | Logo con fondo transparente |
| `kc-logo-256.png` | Logo en la cabecera y el pie de la web |
| `kc-icono-512.png` / `../landing/img/favicon.svg` | Ícono del sitio (pestaña del navegador), versión simplificada |

`build.py` regenera todo (requiere el paquete `@fontsource/cormorant-garamond` y `rsvg-convert`).
