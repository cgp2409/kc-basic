# Web principal (WordPress en kcdigitalmagic.com)

- `landing/`: la página de inicio (diseño original de KC + tienda). Se edita `landing/config.js`.
- `wp/`: cabecera, pie y CSS que usa el resto del sitio (producto, carrito, pago, políticas).

Para aplicar cambios en WordPress, se copia el contenido a la página "Inicio" (bloque HTML) y a las partes de plantilla Cabecera y Pie.
